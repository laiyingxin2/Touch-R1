# License status

No license grant has been added during release preparation. The public repository had no declared license when inspected.

The authors need to specify terms for the original code, trained adapters, original data, and derived annotations. Apache-2.0 is a possible code-license choice used by several reference projects, but has not been selected here. Dataset and weight terms require their own decisions.

The Qwen backbone remains a separate dependency. Public replay data and VTV/Octopi-derived material retain their upstream terms and attribution requirements. The prepared copies and cards are for author review; they do not expand redistribution rights.
